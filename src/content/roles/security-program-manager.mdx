## 직무의 목적과 책임

보안 프로그램 관리자는 이미 합의된 목표가 일정표에만 남지 않도록 여러 조직의 실행을 잇는다. 예를 들어 권한 정비 과제에는 제품팀, IT 운영, 법무, 인사, 보안 엔지니어가 관여할 수 있다. 각 팀의 작업이 서로 의존하는 순서, 의사결정권자, 완료 기준을 명확히 하는 것이 이 직무의 중심이다. 보안 전략을 승인하는 책임과 모든 기술 구현을 수행하는 책임을 한 직함에 임의로 부여하지 않는다.

일반 프로젝트가 하나의 납기와 결과물에 초점을 두는 반면, 프로그램은 여러 과제 사이의 충돌과 장기적인 효과를 추적할 수 있다. 다만 기업별로 Program Manager, Security PM, 보안기획 등의 제목을 다르게 사용하므로 실제 공고의 담당 업무를 읽어야 한다. [NIST CSF 2.0](https://www.nist.gov/cyberframework)은 조직의 보안 결과와 개선 목표를 설명하는 기준이며 채용 직함 목록은 아니다.

## 일하는 흐름

분기 시작에는 CISO나 사업 책임자가 정한 목표를 과제별 책임, 선행 조건, 일정과 검증 기준으로 나눈다. 담당팀이 제시한 공수와 제약을 확인하고 한 과제의 지연이 다른 과제에 미치는 영향을 보여준다. 정기 회의에서는 상태를 색으로만 보고받지 않고 실제 완료 증거, 미결 결정, 다음 책임자를 기록한다. 범위가 바뀌면 이유와 기대 효과, 비용 변화를 승인자에게 다시 알린다.

과제가 완료되면 화면이나 문서가 만들어졌다는 사실만으로 종료하지 않는다. 원래 해결하려던 위험이 줄었는지, 운영팀이 새 절차를 넘겨받았는지, 확인할 수 없는 효과가 무엇인지 점검한다. 사후 회고는 사람을 평가하기보다 의존성 파악과 의사결정이 늦어진 원인을 찾는 데 사용한다.

## 대표 산출물

- **프로그램 계획과 책임표:** 목표, 포함·제외 범위, 작업 간 의존성, 소유자, 승인자, 완료 기준, 주요 의사결정 날짜를 담는다.
- **분기별 성과·위험 보고:** 완료한 일과 남은 위험을 분리한다. 지연 항목에는 단순 사유가 아니라 필요한 결정과 선택 가능한 대안을 적는다.

## 협업과 조직별 범위

보안 엔지니어는 구현의 현실성을, 정책 담당자는 기준과 예외를, 재무·조달은 비용과 계약 제약을, 제품 책임자는 사용자 영향을 설명한다. 프로그램 관리자는 이 전문성을 대체하지 않고 결정이 필요한 시점을 앞당긴다. 한 조직에서는 보안팀 내부 프로젝트만 맡고, 다른 조직에서는 전사 변화를 관리할 수 있다. 조직 규모에 따른 직급과 연봉을 일반화할 자료는 현재 없다.

## 진입과 성장

보안 운영, 개발 프로젝트 관리, GRC, 컨설팅에서 이해관계자 조정과 결과 검증 경험을 쌓은 사람이 전환할 수 있다. 입문 단계에서는 회의록을 정리하는 일보다 미결 결정과 책임을 빠짐없이 추적하는 일로 기여할 수 있다. 경험이 늘면 여러 과제의 우선순위와 예산 충돌을 조정하고, 경영진이 위험을 이해하도록 대안을 설명한다. 특정 프로젝트 관리 자격이 보안 프로그램 관리자 채용의 공통 필수 조건이라고 주장하지 않는다.

## 포트폴리오 예시

가상의 조직에서 계정 정리, 사고 연락 체계, 공급업체 점검이라는 세 과제를 동시에 진행한다고 가정한다. 각 과제의 소유자, 선행 조건, 결정 지점, 확인할 증거를 한 장의 계획으로 만든다. 한 팀의 일정이 늦어지는 상황을 추가해 대안을 두 개 제시하고 어느 위험을 임시로 받아들여야 하는지 기록한다. 면접에서는 '완료'라는 보고와 실제 운영 전환의 차이를 설명한다.

## 채용 근거와 한계

이번 국내 채용 조사에는 `Security Program Manager`라는 **직접 공고가 없다.** 2026-09-11 LINE studio의 [Senior Security Professional](https://careers.linecorp.com/ko/jobs/3111/)은 여러 관리체계·운영 업무가 결합될 수 있음을 보여주지만 프로그램 관리 전담 채용이라고 볼 수 없다. NICE·ECSF와 NIST CSF는 책임과 결과를 구성하는 근거일 뿐 국내 시장의 빈도, 신입 가능성, 필수 자격을 증명하지 않는다. 직접 공고가 확인되기 전에는 이 직무의 현지 채용 조건을 미검증으로 둔다.

# 클라우드 보안 로드맵

클라우드 책임 분담과 신원·네트워크를 이해한 뒤 구성 검증과 사고 관측을 실습한다.

학습 속도는 배경지식과 실습 환경에 따라 달라진다. 각 단계의 완료 기준을 충족했는지 확인하고 다음 단계로 이동한다.

## 1단계 · 책임과 자산 경계

**선수 조건:** 네트워크·운영체제 기초

**학습 목표와 필수 개념:** 서비스별 책임 분담, 계정·프로젝트, 데이터 위치, 네트워크 경로를 그린다.

**권장 실습:** 실습 계정에서 가상 자산과 데이터 흐름을 목록화한다.

**검증 방법과 완료 기준:** 공급자와 고객이 각각 관리하는 구성을 서비스별로 설명한다.

**다음 단계:** 신원과 정책으로 이동한다.

## 2단계 · 최소 권한과 구성

**선수 조건:** 1단계의 자산·경계 이해

**학습 목표와 필수 개념:** IAM 정책, 사람·서비스 계정, 비공개 저장소, 암호화 키와 로그를 다룬다.

**권장 실습:** 읽기 전용과 관리자 역할을 분리해 허용·거부 요청을 시험한다.

**검증 방법과 완료 기준:** 과도 권한 하나를 찾아 수정하고 감사 기록에서 변경자를 확인한다.

**다음 단계:** 관측·운영으로 이동한다.

## 3단계 · 지속 점검과 복구

**선수 조건:** 2단계의 권한 정책 이해

**학습 목표와 필수 개념:** 구성 드리프트, 감사 로그, 경보, 백업·복구를 연결한다. 컨테이너·Kubernetes는 기본 개념을 익힌 뒤 선택한다.

**권장 실습:** 실습 환경의 공개 설정 변화를 탐지하고 복구 절차를 시험한다.

**검증 방법과 완료 기준:** 경보부터 원상 복구까지 걸린 단계와 남은 위험을 기록한다.

**다음 단계:** 플랫폼 또는 아키텍처 전문화로 확장한다.

## 포트폴리오 프로젝트

### 프로젝트 1 · 클라우드 기준 구성

실습 계정에 최소 권한·비공개 저장소·감사 로그를 적용한다.

**완료 기준:** 허용·거부 접근 테스트와 정책 변경 이력을 남긴다.

### 프로젝트 2 · 구성 오류 대응 연습

의도적으로 만든 공개 구성 오류를 탐지하고 되돌린다.

**완료 기준:** 탐지 시각, 영향 범위, 원인, 복구 확인과 재발 방지 통제를 제시한다.

## 관련 기술 문서와 공식 자료

관련 기술: 네트워크 기초, 신원 및 접근 관리, 클라우드 보안, 제로 트러스트 아키텍처, 보안 로그와 SIEM, 컨테이너 보안, 쿠버네티스 보안.

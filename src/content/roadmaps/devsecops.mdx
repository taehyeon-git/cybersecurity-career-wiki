# DevSecOps 로드맵

개발 파이프라인의 안전한 권한에서 시작해 코드·의존성·이미지·배포 통제를 단계적으로 자동화한다.

학습 속도는 배경지식과 실습 환경에 따라 달라진다. 각 단계의 완료 기준을 충족했는지 확인하고 다음 단계로 이동한다.

## 1단계 · 안전한 개발·자동화 기초

**선수 조건:** Git과 프로그래밍 기초

**학습 목표와 필수 개념:** SSDF의 개발 관행과 CI 작업의 트리거·권한·비밀정보를 학습한다. 서비스 계정에 최소 권한을 적용한다.

**권장 실습:** 실습 저장소에 빌드와 단위 테스트를 자동화하고 외부 PR에서 배포 토큰에 접근할 수 없는지 확인한다.

**검증 방법과 완료 기준:** 파이프라인이 성공·실패를 재현하고 각 작업의 권한을 설명한다.

**다음 단계:** 코드·의존성 검사로 이동한다.

## 2단계 · 검사와 산출물 추적

**선수 조건:** 1단계의 파이프라인 이해

**학습 목표와 필수 개념:** SAST, SCA, SBOM의 대상과 한계를 구분한다. 새 위험의 차단 기준과 예외 검토 절차를 적는다.

**권장 실습:** 실습 앱에서 취약 코드를 넣어 검사를 시험하고 배포 버전에 대응하는 SBOM을 보관한다.

**검증 방법과 완료 기준:** 검사 결과의 오탐 검토와 실제 수정 이력이 PR에 남는다.

**다음 단계:** 컨테이너와 배포 보안으로 이동한다.

## 3단계 · 컨테이너·클러스터 적용

**선수 조건:** 2단계의 검사 운영, 컨테이너 기본 개념

**학습 목표와 필수 개념:** 이미지 최소화·비루트 실행을 먼저 검증한 뒤 Kubernetes Pod·RBAC·시크릿·네트워크 정책을 배운다.

**권장 실습:** 로컬 클러스터에 제한된 서비스 계정으로 앱을 배포하고 허용·거부 접근을 시험한다.

**검증 방법과 완료 기준:** 이미지·배포 설정·접근 정책을 검증한 증거와 운영 예외가 정리된다.

**다음 단계:** 공급망·플랫폼 전문 영역으로 확장한다.

## 포트폴리오 프로젝트

### 프로젝트 1 · CI 검사 파이프라인

빌드, 테스트, SAST, SCA, SBOM 생성을 점진적으로 추가한다.

**완료 기준:** 취약 변경이 탐지되고 수정 후 통과하며 토큰 권한과 예외 만료를 문서화한다.

### 프로젝트 2 · 안전한 배포 실습

비루트 이미지와 최소 RBAC를 적용해 교육용 앱을 배포한다.

**완료 기준:** 금지된 Secret 조회가 거부되고 배포 후 정상 기능은 유지됨을 확인한다.

## 관련 기술 문서와 공식 자료

관련 기술: 프로그래밍과 스크립팅, 안전한 개발 수명주기, 정적 애플리케이션 보안 테스트, 소프트웨어 구성요소 분석, 소프트웨어 자재 명세서, CI/CD 보안, 컨테이너 보안, 쿠버네티스 보안.

# 보호 대상 중심 보안 분야 구현 계획

1. 공식 자료와 현행 60개 직무를 대조해 15개 보호 대상 분야와 관련 직무를 정한다. 분야·직무군의 목적과 경계를 설계 문서에 기록한다.
2. 분야 콘텐츠 스키마를 직무군 `category`에서 분리하고 명시적 `roleIds` 다대다 연결 및 검사를 추가한다. 누락·중복·초안 직무 참조를 검사한다.
3. 15개 새 MDX를 쓰고 9개 옛 기능별 분야 MDX를 제거한다. 각 문서에 쉬운 설명, 현장 판단, 세부 갈래, 관련 직무, 공고 확인과 한계를 넣는다.
4. 홈·분야 목록·사이드바·상세·직무 역링크·처음 읽기 문구를 새 구조에 맞춘다. 옛 분야 URL은 정적 이동 안내를 제공한다.
5. 검색·사이트맵·빌드 검증·테스트·README와 작성 지침을 새 개수와 의미로 갱신한다. 모바일·데스크톱 렌더링을 점검한다.
6. 콘텐츠·타입·린트·단위·E2E·정적 출력 검사를 통과시킨 뒤 기존 GitHub Pages 저장소에 배포하고 공개 주소를 확인한다.

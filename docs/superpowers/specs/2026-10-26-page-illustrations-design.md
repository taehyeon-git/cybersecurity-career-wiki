# 페이지별 삽화 디자인

## 의도와 범위

독자가 위키의 각 페이지를 열었을 때 주제를 빠르게 알아볼 수 있는 그림을 한 개씩 보여 준다. 기존의 오래된 폴더형 위키 분위기와 본문 중심 읽기 흐름을 유지한다. 정규 공개 경로 96개(홈·안내·분야 목록·직무 목록·경로 목록·용어집 6개, 분야 15개, 직무 60개, 경로 15개)를 모두 포함한다. 이전 분야 주소 9개에도 시각적 빈칸이 없도록 같은 시스템을 적용한다.

## 접근 방법

- 페이지별 비트맵 파일: 장면마다 완전히 다른 그림을 만들 수 있지만 약 96개 파일의 제작·품질관리·전송 비용이 크다.
- 몇 개의 공통 이미지 반복: 구현은 빠르지만 ‘각 페이지마다’의 식별성이 약하다.
- **선택: 데이터에 따라 달라지는 인라인 SVG 삽화.** 분야·직무·경로와 페이지 식별자에 따라 장면의 상징·구성·색 강조가 달라진다. 파일 다운로드가 없고 정적 배포와 확대·축소에 맞다.

## 화면과 내용

삽화는 제목과 요약 옆이나 바로 아래의 작은 편집 그림으로 배치한다. 구식 문서 카드·종이 격자·잉크 선·절제된 파랑과 황토색을 사용하고, 실제 업무나 보호 대상을 암시하는 형태를 그린다. 글자를 그림 속에 반복해 넣지 않는다. 모바일에서는 폭을 줄이고 제목을 밀어내거나 가로 스크롤을 만들지 않는다. 다크 모드에서도 선과 배경이 구분되어야 한다.

## 접근성과 검증

각 그림은 정확히 하나의 SVG이며, 한국어 접근성 이름으로 해당 페이지의 주제를 알려 준다. 내부 도형은 보조기기에 중복 노출하지 않는다. 정적 빌드 결과의 96개 정규 HTML에서 그림 존재·개수·이름을 검증하고 대표 페이지를 320px·390px 화면에서 확인한다. 페이지별 삽화가 직무 사실이나 채용 자격을 새로 주장하지 않도록 장식과 개념 안내 범위로 제한한다.

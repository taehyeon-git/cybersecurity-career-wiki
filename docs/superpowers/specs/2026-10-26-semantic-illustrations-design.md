# 직무 중심 장면 삽화 개편

## 목표

현재 96개 정규 페이지의 그림은 분야·직무·경로별 아이콘만 바뀌고 구도는 거의 같다. 독자가 그림만 봐도 페이지에서 다루는 **보호 환경, 실제 업무 또는 커리어 단계**를 떠올릴 수 있도록 모든 그림을 장면형 삽화로 다시 만든다. 기존의 오래된 폴더형 위키 분위기와 본문 중심 배치는 유지한다.

## 시각적 방향

- 320×200 인라인 SVG 한 장을 각 페이지 머리말에 둔다. 종이색 바탕, 잉크색 윤곽, 절제된 포인트색을 사용한다.
- 직무는 대상·행동·결과물의 관계를 그린다. 예를 들어 보안관제 분석가는 경보 목록을 분류해 인계 티켓으로 연결하고, OT 보안 엔지니어는 가동 중인 설비 옆에서 변경 기록과 안전 제약을 확인한다.
- 분야는 보호 환경 자체를 그린다. 공장, 차량, 서버실, 브라우저 서비스, 데이터 보관·공유 등 서로 다른 실루엣을 사용한다.
- 경로는 기술 강의 순서가 아니라 공고 탐색·업무 샘플·지원 준비처럼 해당 커리어의 결정과 산출물을 그린다.
- 상위 여섯 페이지에는 위키 색인·서랍·읽기 책상·직무 게시판·경로 표·용어 카드처럼 목적이 다른 장면을 사용한다.
- 그림 속 글자는 넣지 않는다. 과장된 해커 이미지, 직무별 자격·채용 사실을 암시하는 표현도 넣지 않는다.

## 구현 선택

기존 벡터 기반 디자인을 유지하되, 반복되는 도형 틀과 아이콘 쌍을 **명시적인 페이지별 장면 데이터와 여러 화면 구성**으로 교체한다. 96장의 별도 비트맵을 생성하면 제작·검수·전송 비용이 크고, 현재 작은 그림 크기와 다크 모드에 맞추기도 어렵다. 단순 아이콘 교체는 이미 사용자 피드백에서 부족하다고 확인되었다.

`PageIllustration`은 공통 접근성·크기·색만 담당한다. `RoleScenes`는 60개 직무, `DirectoryScenes`는 15개 분야·15개 경로·색인 페이지의 장면을 담당한다. 공개 슬러그에는 침묵하는 정규식 대체 그림을 사용하지 않는다. 과거 주소와 404는 별도 장면으로 처리한다.

## 품질 기준

- 공개 96페이지 모두 정확히 한 장이며, 페이지별 장면 설명이 한국어 접근성 이름으로 읽힌다.
- 이전에 같은 아이콘 쌍이던 직무(예: 관제 분석가와 위협 인텔리전스 분석가)도 다른 장면으로 보인다.
- 320px·390px 모바일, 데스크톱, 라이트·다크 모드에서 그림이 제목을 밀거나 가로 스크롤을 만들지 않는다.
- 본문 내용·링크·정적 내보내기와 검색 동작은 보존한다.

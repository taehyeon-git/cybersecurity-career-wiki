# 직무 인벤토리

기준일: **2026-10-25**. 공개 직무 페이지 **47개**를 실제 `src/content/roles/` 파일과 대조한 목록입니다. 이는 [NCS 정보보호 SQF](https://www.ncs.go.kr/sqf/sqf01/sqf10100201p1.do?iscCd=20&iscNm=%EC%A0%95%EB%B3%B4%EB%B3%B4%ED%98%B8)의 실무 영역을 참고해 여섯 탐색 범주로 구성한 위키의 안내 체계입니다. NCS의 **5개 하위산업분야**와 위키의 **6개 폴더**는 같은 단위가 아닙니다. NCS의 공식 직종 목록을 그대로 복제하거나 각 위키 직무가 독립 채용 직함으로 널리 쓰인다고 주장하지 않습니다. [NICE](https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center/nice-framework-current-versions)와 [ENISA ECSF](https://www.enisa.europa.eu/publications/european-cybersecurity-skills-framework-role-profiles)는 업무 범위를 검토하는 보조 근거입니다.

표의 P번호는 [국내 채용공고 표본](korean-job-market.md)에 연결됩니다. **본문**은 공식 공고 본문에서 관련 업무를 확인했다는 뜻이며 독립 직함 확인을 뜻하지 않습니다. **제목만**은 공식 목록·제목만 확인하고 상세 직무 요건은 검증하지 못했다는 뜻입니다. **인접**은 한 공고 속 관련 업무를 찾았으나 해당 직무 전체를 대표하지 않는다는 뜻입니다. **표본 없음**은 이번 74개 식별자 조사에서 직접 근거를 확보하지 못했다는 뜻이지 직무가 없거나 수요가 낮다는 뜻이 아닙니다. P01·P19·P21의 상세 원문은 현재 다시 열 수 없고 P43은 상세 확인을 보류했습니다. P19·P21과 비슷한 업무의 새 원문 P28·P29를 별도로 기록했습니다. P60·P61은 공식 본문을 확인했지만 별도 Chrome 세션에서 접근 제한이 재현됐습니다.

## 범위와 갱신 기준

- 같은 회사의 `Security Engineer`나 `Security Researcher` 한 공고가 여러 업무를 맡길 수 있습니다. 표의 연결은 각 행마다 독립 채용 건수로 세지 않습니다.
- 이름이 넓은 역할과 분야별 특화 역할은 채용시장 규모가 확인된 순서가 아니라 **주 책임과 산출물**을 기준으로 별도 페이지를 둡니다. 조직에서 합쳐 맡을 수 있습니다.
- 공고 표본은 편의 표본입니다. 특정 역할의 채용 수요, 신입 가능성, 필수 자격증·학력·경력연수를 일반화하지 않습니다.
- 공개 경로는 `/careers/{slug}/`입니다. 페이지 수가 달라지면 실제 MDX 파일의 `publicationStatus`를 다시 집계하고 이 목록을 갱신합니다.
